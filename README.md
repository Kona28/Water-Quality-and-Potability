Analisis dan Klasifikasi Kualitas Air (Water Potability) Menggunakan Machine Learning
Repositori ini berisi proyek prapemrosesan data (data preprocessing) dan analisis kualitas air untuk memprediksi tingkat kelayakan air minum berdasarkan parameter fisik dan kimia air.

📋 Tentang Proyek
Proyek ini dibuat untuk memenuhi tugas praktikum Machine Learning. Tujuannya adalah melakukan pembersihan data secara komprehensif mulai dari penanganan missing values, eliminasi outlier menggunakan metode IQR (Interquartile Range), hingga standardisasi fitur, agar dataset bersih dan siap digunakan untuk pembangunan model klasifikasi.

🛠️ Teknologi & Pustaka yang Digunakan
- Python (Bahasa pemrograman utama)
- Jupyter Notebook (.ipynb — Lingkungan pengembangan interaktif)
- Pandas & NumPy (Manipulasi, pembersihan, dan perhitungan matriks data)
- Scikit-Learn (StandardScaler untuk standardisasi fitur)
- Matplotlib & Seaborn (Visualisasi data dan distribusi statistik)

📂 Struktur File di Repositori
- Water_Quality_Preprocessing.ipynb: Berisi baris kode lengkap untuk eksplorasi data, penanganan nilai kosong, pembersihan outlier, hingga standardisasi.
- water_potability.csv: Dataset utama yang berisi parameter pengujian kualitas air dan status target Potability.
- Laporan Machine Learning - Water Quality...: Dokumen laporan lengkap hasil praktikum.
